# HEMINGREPO
heming's_repository
What this is：
A generative art sketch based on Georg Nees' *Schotter* (1968).

How to Run
python3 sketch.py
The program will generate a `sketch.svg` file.

Parameters
- `COLS`: number of columns
- `ROWS`: number of rows
- `SEED`: controls the random pattern
- `CHAOS`: controls the amount of disorder
- `SQUARE`: size of each square
- `MARGIN`: margin around the artwork
